# 서비스 모델 보관 안내

이 폴더에는 포트폴리오 재현을 위한 최종 V7 YOLO 가중치 파일 하나를 둡니다.

- 로컬 실행: `smart_cart.pt`를 이 폴더에서 직접 읽습니다.
- Cloud Run 배포: Docker 이미지가 이 파일을 함께 포함하므로 별도 API 키, Cloud Storage, 모델 다운로드 과정이 필요 없습니다.
- 학습 데이터와 V8 등 중간 실험 가중치는 공개하지 않습니다.

최종 서비스 모델은 V7이며, 상세 학습 정보는 `docs/로컬_YOLOv8_최종_모델_기록.md`에서 확인할 수 있습니다.
