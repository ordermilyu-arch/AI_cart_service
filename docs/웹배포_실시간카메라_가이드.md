# Smart Cart 웹 배포와 실시간 카메라 인식 가이드

이 프로젝트는 직접 학습한 **V7 YOLOv8 모델**을 `backend/models/smart_cart.pt`에 포함한다. 따라서 Roboflow API 키, Cloud Storage 버킷, 별도 모델 다운로드 없이 GitHub의 소스로 웹 서비스를 배포할 수 있다.

## 최종 구성

```text
GitHub main push
  ├─ Vercel: React 화면 자동 배포 (HTTPS)
  └─ Cloud Build Trigger: Python API와 V7 모델을 Docker로 빌드
                         → Cloud Run GPU 자동 배포

브라우저 카메라 → 1.8초마다 JPEG 1장 전송 → Cloud Run GPU YOLOv8 → 상품 결과 반환
```

카메라 영상은 브라우저의 `getUserMedia()`로 표시한다. 서버에는 동영상 전체가 아니라 인식용 JPEG 프레임만 전송한다. 현재 서비스는 신뢰도 75% 이상이고 같은 상품이 2회 연속 확인될 때만 장바구니에 넣는다.

## 1. Google Cloud 준비

1. Google Cloud 계정을 만들고 **결제(Billing)** 를 연결한다. GPU Cloud Run은 유료 자원이다.
2. 새 Google Cloud 프로젝트를 만든다.
3. Cloud Run, Cloud Build, Artifact Registry API를 활성화한다.
4. Cloud Run GPU가 지원되는 리전을 선택한다. 예시는 `us-central1`이며, 실제 생성 전 Cloud Run 콘솔에서 NVIDIA L4 GPU 사용 가능 여부를 확인한다.

## 2. GitHub → Cloud Run GPU 자동 배포

1. 이 저장소를 새 GitHub 저장소에 push한다. `backend/models/smart_cart.pt`는 포함되어야 한다.
2. Google Cloud Console → **Artifact Registry**에서 Docker 저장소를 한 번 만든다.

```bash
gcloud config set project PROJECT_ID
gcloud artifacts repositories create smart-cart \
  --repository-format=docker --location=us-central1
```

3. Google Cloud Console → **Cloud Build → Triggers → Create trigger**를 연다.
4. GitHub 계정을 연결하고 이 저장소의 `main` 브랜치 push를 선택한다.
5. 구성 파일로 저장소 루트의 `cloudbuild.yaml`을 선택한다.
6. `_REGION` 값을 실제 L4 GPU 지원 리전으로 설정한다.

Cloud Build 기본 서비스 계정에는 Artifact Registry Writer, Cloud Run Admin, Service Account User 권한이 필요하다. Trigger를 저장한 뒤 `main`에 push하면 Python API와 V7 모델이 포함된 Cloud Run GPU 컨테이너가 자동 갱신된다.

## 3. Vercel로 화면 배포

1. [Vercel](https://vercel.com)에 GitHub로 로그인한다.
2. **Add New → Project**에서 이 GitHub 저장소를 Import한다.
3. Root Directory는 `frontend`로 지정한다.
4. Cloud Run 배포가 끝난 뒤 받은 주소를 Vercel 환경 변수로 추가한다.

```text
VITE_API_BASE_URL=https://smart-cart-api-xxxxx-uc.a.run.app/api
```

5. Deploy를 누른다.

Vercel은 HTTPS 주소를 자동 제공한다. 카메라는 HTTPS 또는 localhost에서만 권한 요청이 가능하므로, 배포 주소에서 최초 한 번 브라우저의 카메라 권한을 허용해야 한다.

## 배포 후 확인

1. Cloud Run URL 뒤에 `/api/health`를 붙여 `model_exists: true`인지 확인한다.
2. Vercel 웹 주소를 열고 카메라 권한을 허용한다.
3. 모델이 포함된 상태로 상품을 카메라에 비춘다.
4. 메인 상단의 카메라 상태 버튼을 눌러 디버그 정보를 켜고 모델 클래스·신뢰도·DB 연결 상태를 확인한다.

## 비용과 반응 속도

`cloudbuild.yaml`은 첫 카메라 사용 시 지연을 줄이기 위해 GPU 최소 인스턴스를 1개로 설정했다. 이 설정은 사용자가 없어도 비용이 발생한다. 단순 시연 시간 외에는 `--min-instances=0`으로 낮추면 비용을 줄일 수 있지만, 다음 첫 인식은 GPU·모델 기동 시간만큼 늦어질 수 있다.

## 공개 범위

- 최종 V7 `.pt` 모델 하나와 학습·평가 소스는 포트폴리오 재현을 위해 공개한다.
- 원본 이미지 데이터셋과 중간 실험 가중치는 제외한다.
- 모델을 공개하기 전 학습 데이터셋의 모델 가중치 재배포 허용 여부를 확인한다.
- Roboflow API 키, Cloud Storage 키 등 비밀 정보는 사용하거나 저장하지 않는다.
